# SMPL-X model assets

Place the licensed SMPL-X files under:

```text
weights/
  smplx/
    smplx/
      SMPLX_NEUTRAL.npz
      SMPLX_MALE.npz
      SMPLX_FEMALE.npz
      smplx_uv_2021.obj
      smplx_uv_2021.png
```

The default path is project-relative. It can be overridden with the
`SMPLX_DIR` environment variable.
